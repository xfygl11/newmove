# 资产出镜状态（Asset Appearance States）

在每段内按时间轴登记角色 / 场景 / 道具的出镜状态，供后续资产生成与镜头绑定使用。

## 角色（characters）

- 仅登记本段真实出镜或发声的角色。
- `timeline[].state` 从 9 类词表取：实际出镜并说话 / 实际出镜未说话 / 仅手部出镜 / 画外仅对白 / 仅背影 / 剪影 / 遮挡 / 出场瞬间 / 退场瞬间。
- `timeline[].range` 为该状态在本段全局时间轴上的区间，如 `00:00-00:05`。

## 场景（scenes）

- 登记锚点、机位、前中后景、空间关系；无法从原文确证的留空或标「待定」。
- `timeline[].range` 覆盖该场景在本段持续的时间区间。

## 道具（props）

- 登记段首位置/持有者、时间轴动作、段末状态、禁止项；无法确证的标「待定」，不编造。
- `timeline[].range` 为动作发生的时间区间。

## 结构

```json
"assets": {
  "characters": [
    {"name": "角色A", "timeline": [{"range": "00:00-00:05", "state": "实际出镜并说话"}]}
  ],
  "scenes": [
    {"name": "老宅客厅", "timeline": [{"range": "00:00-00:12", "state": "前中后景：…；机位：…；空间关系：…"}]}
  ],
  "props": [
    {"name": "道具X", "timeline": [{"range": "00:00-00:03", "state": "段首在角色A手中；动作：拿起；段末：握持；禁止：结构变化"}]}
  ]
}
```

三个数组都必须存在；无对应资产时为空数组。
