# 节拍解析与分段（Beat Parsing & Segmentation）

把定稿剧本拆成「源剧情账本 E##」，再合并为分段 G##。你只导演，不编剧。

## 全量原子节拍解析

1. 按剧本原文顺序逐条登记节拍，编号 `E01/E02/...`，**全部保留，不筛掉、不合并、不重排**。
2. 节拍类型 ∈ 对白 / 动作 / 反应 / 信息 / 过渡留白。
3. 每条记录：
   - `id`：E##。
   - `sceneSeq`：来源场次序号（对应剧本 `scenes[].seq`，同一场可含多条节拍）。
   - `type`：节拍类型。
   - `who`：谁做 / 谁说，无人称留空字符串。
   - `content`：动作或对白原文，不改写。
   - `object`：作用对象（道具/人/地点），无则空字符串。
   - `estDurationMs`：最低自然时长（毫秒）。
   - `tags`：五类关键标签数组，只标注不删减不重排，无则 `[]`。
4. 任何「会改变剧情状态」的句子必须能映射回某个 `E##`，否则视为新增剧情，删除。

## 五类关键标签

- 转折点
- 情绪峰值
- 信息增量点
- 决策点
- 沉默点

## 时长预算（借鉴 Toonflow PART A A2.3 / A3.0 / A3.2）

公式：

```text
节拍最低时长 = 自然对白时间 + 必要停顿 + 必须串行动作/反应时间
```

- 对白按自然语速估算；串行动作/反应相加；并行动作取重叠，不重复计。
- 能自然同时发生的「说话 + 小动作」重叠计时；必须先后发生的因果动作相加。
- 长对白不按「长句固定 3–3.5s」粗估，按实际文本长度、停顿、语气估算。
- 不确定时宁可留 **10%–20% 呼吸余量**，不靠异常快语速硬塞。
- 关键停顿、反应、转身、走位不被对白完全吞掉。
- 开场建立「辨认 → 反应 → 行动」的最低时间（借鉴 screenAdaptation §1：观众需要看清正在发生的事并形成等待）；依赖迟疑、尴尬或失落的段落保留反应时间，不套固定秒数。

**段数下限只作参考**：`⌈目标总时长 / 单段上限⌉` 只回答「至少需要几段」，不强制实际段数等于它。对白/动作很轻可以 15+15+15+10，剧情密度高可以 12+11+11+11+10；每段不超上限、总和符合目标、剧情完整即可。原则是在「不过密」和「不碎片化」之间取平衡。

**对白时长硬门槛（A3.2）：**
- 禁止用异常快语速解决时长不够；
- 禁止因为时长不够删词、改词、吞句尾；
- 冲突时优先压缩自己添加的空镜、无信息停顿、冗余运镜；用户原文明确要求的空镜、停顿、留白不得压缩或删除；
- 仍不够时在输出里标注「时长约束冲突」，不删台词也不假装满足。

## 合段六条准绳（A2.4，全部满足才继续合并）

1. 合并后总时长 ≤ 单段上限（含 10% 呼吸余量）；
2. 所有对白都能以自然语速说完；
3. 关键因果动作有完整过程；
4. 至少留得下必要反应与呼吸；
5. 不因塞得过满导致每 1–2 秒就强制切镜；
6. 段末可以形成清晰、可在下一段重新声明的状态。

## 强制开新段六条（A2.4，命中任一即截断）

- 对白已经接近本段时间预算上限；
- 同段需要过多彼此竞争的动作/反应；
- 情绪或目标发生明确阶段切换；
- 场景或时间发生切换；
- 继续合并会破坏段间可独立生成性；
- 需要异常语速、瞬移动作或省略反应才能塞下。

## 分段

1. 给定单段时长上限（毫秒）。
2. 从前往后合并相邻节拍为段 `G01/G02/...`，按合段六条准绳判定是否继续合并；不删、不改、不改顺序。
3. `globalTimeRange` 为全局时间区间，如 `00:00-00:12`；段首从 00:00 起连续累计。
4. `batch` 只表示输出批次边界，不改全片顺序/段号/连续性。
5. 先全片规划再分批；批次大小只影响一次输出多少段，段号与时间轴不变（借鉴 Toonflow PART A A3）。
6. 超过单批容量上限时保持全局段号连续，仅拆成多个 batch；未交付内容称「下一批待交付段」，不称「被切掉」。

## 输出片段

```json
{
  "globalDurationMs": 55000,
  "beats": [
    {"id": "E01", "sceneSeq": 1, "type": "动作", "who": "角色A", "content": "拿起道具X", "object": "道具X", "estDurationMs": 2000, "tags": ["信息增量点"]}
  ],
  "segments": [
    {"id": "G01", "batch": 1, "durationMs": 12000, "globalTimeRange": "00:00-00:12", "beatRefs": ["E01", "E02"], "assets": {"characters": [], "scenes": [], "props": []}}
  ]
}
```

`segments[].assets` 结构见资产出镜状态规则，不得留字段缺失。
