# 视听化改编（Screen Adaptation）

把小说段落改编为分场剧本。每场是「在某个时间地点，谁做了什么、说了什么、听到什么」，全部用视听可拍的语言表达，不保留心理描写与抽象抒情。

## 五步流程

1. 锁定改编范围：只处理给定原文，不扩展前后情节。
2. 提取：事件、人物、对白、未解信息。
3. 视听化：叙述→动作，心理→可见行为，抽象→具体可拍。
4. 组织：场次顺序、对白、声音（音乐/音效）。
5. 忠实度检查：每处视听表达都能指回原文依据。

## 原文依据映射（借鉴 Toonflow screenAdaptation §1）

改编前先提取本次人物目标、阻碍、失败代价与关键变化，再逐项判断它在原文中怎样成立、观众在剧本中怎样得知：

| 原文内容 | 选择表达方式时检查 | 交给剧本的结果 |
|---|---|---|
| 正在发生的事件 | 谁在何处做了什么，改变了什么 | 有起止状态的动作 |
| 人物心理或关系判断 | 当前什么触发它，怎样影响选择，能看到什么后果 | 可见的反应与策略变化 |
| 过去经历或世界规则 | 本次哪次选择必须依赖这条信息，原文有什么证据 | 按需出现的对白、物件、声音或简短旁白 |
| 未解信息 | 本次是否允许揭晓，角色与观众分别知道多少 | 保留未知或有明确依据的揭示 |

记录事件事实与讲述顺序两层：改成倒叙可能不改事件，但会改观众的判断和期待，需检验揭示时机。不默认所有文学表达都该删掉；旁白有叙述功能时保留。

## 场景任务链（借鉴 screenAdaptation §2）

每场先确定「本场结束后哪件事会不同」，再用动词写人物眼下实际要完成的动作（让对方留下、取回记录、阻止签字），尽量能判断当场成败，避免只写「获得理解」。按「目标 → 阻碍 → 行动 → 反应 → 策略调整 → 结果」整理：对手也有当下目的，环境或规则会形成具体限制；先成立行动再写对白。结尾标明局势、关系、资源、信息或选择中哪一项改变，结果如何造成下一场；变化可以渐进，不要求每场翻转。

## 心理变化反查（借鉴 screenAdaptation §3）

出现「他终于明白」「她失去信任」等承担关键推进的结论句时：

1. 找出变化前仍在起作用的限制（不愿交出决定权、不相信某条消息），依据来自已写出的行为；原文没有的习惯不能当作改编事实。
2. 写清变化后多了哪一种可能（对方能够参与、某物开始被使用），先确定实际差异，再从场景已有的人物和物件中选足以表现它的动作，不按情绪名称套手势。
3. 回到转变时刻检查：人物得到了什么新证据、遭遇了什么后果？若不足以使他改变，应修补理由或放缓转变，不能让一个动作凭空证明他已经想通。
4. 变化要写回连续表演：对方能否察觉并回应、后场是否沿用结果。把过程写成可表演的关键行为，不靠增加表情形容词。

## 信息差与揭示时机（借鉴 screenAdaptation §4）

先写该信息的真实内容和依据，再记每个相关角色与观众此刻各知道什么：

| 信息关系 | 适合效果 | 执行要点 |
|---|---|---|
| 观众先知道 | 担心、期待人物发现 | 给观众清楚证据，人物未知有合理原因，后续行动逼近后果 |
| 角色先知道 | 好奇、重新理解人物 | 观众至少知道值得追问的问题，隐瞒符合目的，不靠故意不给必要画面拖延 |
| 同时得知 | 冲击、共情、选择压力 | 给信息辨认与反应时间，随后改变行动，不止停在解释谜底 |

把重要信息安排在会影响下一次判断或选择的位置；反转应重新解释已有线索，误导可来自人物误判或证据不完整，不能让已客观展示的事实无故失效。

## 忠实度模式

- 严格保留：不得删并事件、不得新增对白、不得改动视角，只做必要视听转写。
- 允许合理压缩：可删并次要事件、合并相邻场景，但每处删并/新增对白/改视角都必须单独列在 `proposals`。

## 对白规则

- 优先保留原文对白，不做改写；必要时用 type 标注 OS（画外）或 VO（旁白）。
- 对白有目的（潜台词），避免直说感受、复述画面。
- 新增对白只能出现在 `proposals` 里，不能混入 `scenes` 正稿。

## 输出格式（JSON）

```json
{
  "scenes": [
    {
      "seq": 1,
      "location": "地点",
      "time": "时间",
      "characters": ["出场人物"],
      "summary": "本场事件一句话",
      "action": "可拍的动作与画面",
      "dialogue": [
        {"speaker": "说话人", "type": "对白", "text": "台词"}
      ],
      "sound": {"music": ["音乐"], "sfx": ["音效"]},
      "startState": "入场状态",
      "endState": "退场状态",
      "transition": "转场"
    }
  ],
  "proposals": [
    {"type": "新增对白|删并事件|改视角|其他", "text": "提案内容", "source": "原文依据"}
  ]
}
```

其中 `dialogue[].type` ∈ 对白 / OS / VO；`sound` 为对象，`music` 与 `sfx` 均为字符串数组。
