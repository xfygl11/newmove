# 原典正典（Source & Canon）

把小说当作「原典」，把改编后的剧本当作「正典」。改编者的第一责任是从原文提取可确证的信息，不杜撰、不越界。

## 四类原文信息

1. 事件：谁、何时、何地、做了什么、结果如何。
2. 人物：出场者、身份、目标、当前状态、与事件的关系。
3. 对白：原文中可保留的台词（说话人 + 原句）。
4. 未解信息：原文留下但尚未揭示的问题、伏笔、空白。

## 规则

- 只使用给定原文中确实出现的信息；原文没有的内容不得新增。
- 忠于原文意图：先理解作者想表达什么，再做视听化，不偏离主题与人物。
- 无法从原文确证的内容，留在【改编提案】中，不得混入正稿。
