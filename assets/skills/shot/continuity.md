# 连续性与段间衔接（Continuity & A7）

分镜阶段只做「文字层」的连续性把控，不评价画质、口型、运动——那些在生成之后由人验收。

## 可溯源原则

- 角色的衣着、携带物、伤情、情绪变化必须能映射回源剧情（E## 节拍或资产出镜状态）；无依据的变化不写进分镜。
- 空间关系：同一场景内角色的相对位置（左右/前后）保持一致，除非剧情明确写明移动。
- 动作衔接：上一帧/上一段结束时的动作状态，是下一帧/下一段的起点；只继承源剧情已定义的状态。
- 道具：持有者、位置、完好度跨帧一致，变化必须有 E## 依据。

## 段间衔接（A7）

相邻两个独立生成的段（互不共享同一次生成过程），至少满足其一，否则并排观看会误读为同一镜头的错误续帧：

1. **拍摄主体不同**：两段画面的主要角色/对象没有交集。
2. **景别差 ≥ 2 档**：远景 / 全景 / 中景 / 近景 / 特写 五档，档位差至少 2（如全景→近景）。
3. **角度差 ≥ 90°**：平视↔俯视、平视↔仰视 视为 45° 差；正面↔侧面、侧面↔背面 视为 90° 差；正面↔背面 视为 180°。

三条都不满足时，优先改景别（保守），其次改角度；禁止用改剧情来解决衔接问题。

## 校验提示（给人看）

发现衔接不足时，用一句话指出「哪两段、缺什么」：

- 「G02 与 G03 主体相同（阿青），景别仅差 1 档，角度相同——建议把 G03 改为近景或侧面。」
- 「G04 与 G05 主体与景别相同，角度差不足 90°——建议 G05 改为背面或俯视。」

不输出改动后的完整提示词，改动由导演或用户确认后进行。

## 道具状态链（借鉴 PART A A8.3/A12.11）

对剧情关键道具，逐帧维护一条状态链：`持有人 / 绝对位置 / 可见或被遮挡 / 数量 / 开合状态 / 损耗污渍 / 本帧动作 / 帧末状态`。

硬规则：

- 一人物连续镜头里持有某道具，且源剧情没有「放下/递出/收起/掉落」事件，下一时刻**不能凭空消失**。
- 下一帧裁掉手或道具、被身体遮挡 → 允许「暂时不可见」，但世界状态保持；**「没拍到」不等于「道具消失」**。
- 已放下的道具不能无过程回到手里；已交给 B 的物件不能同时又在 A 手里；数量不能无因增减。
- 画面左右可因合法换机位而变，世界位置不能因此改变；换机位时先核对世界坐标再重算画面描述。
- 禁止无因恢复或重置：喝过的杯子突然满、擦开的污渍复原、打开的门无动作闭合。

## 穿帮风险审计（借鉴 PART A A12.18.1，输出前单向执行一次）

对相邻帧对（同段内）与相邻段对（同场景连续时间）建立「起态 → 末态」快照比较，只查不改剧情：

1. **人物穿帮**：无来源瞬移、无来源换边、无过程站↔坐、同一位置重复出现两个同一人物、画内画外与机位描述矛盾。
2. **道具穿帮**：无来源消失/复制/换手/回手、数量变化、状态重置；特别查「上一秒还拿着，下一秒同一只手清楚可见却空了」。
3. **空间穿帮**：固定家具移位、门窗状态跳变、人物穿墙穿桌、镜像反射中出现不存在的人或物。
4. **修正边界**：发现 AI 草稿自身矛盾 → 直接修成与源剧情一致；发现源剧情自身矛盾 → 保留原文并标注「源文本冲突」，不擅自编桥接剧情。

## 结构自检（借鉴 Toonflow PART A A11/A12）

输出前自查，逐项通过再交付：

1. **可溯源**：每个改变剧情状态的描述都能映射回某个 E##；找不到依据的删掉。
2. **段号完整**：globalSeq 与输入分段一一对应，不新增、不遗漏、不改顺序。
3. **refs 有效**：每个 stableId 都存在于输入资产清单；找不到的省略，不编造。
4. **站位自包含**：每段 blocking 含世界坐标/画面坐标/光源/道具位置/段末状态 5 块，无「延续上一段」字样。
5. **表演可拍**：无心理活动、无不可见通道的表演描述；情绪均由可见行为承载。
6. **穿帮预检**（A12 穿帮审计简化）：同段内前后帧的角色左右关系未无故颠倒；道具持有者与段首登记一致；已退场的角色不再出现在画面描述中。
7. **防循环边界**（A12 防死循环简化）：每段只描述本段时间轴；不用「更震撼、更激烈」这类无限升级词，强度以源剧情 E## 为上限。
