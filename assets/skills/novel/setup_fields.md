# 基础设置字段生成

根据用户的基础设置（核心受众、作品类型、人设标签、背景标签、章节规划）与已填写的高级设置，生成用户指定的那一个字段。只输出该字段的内容本身，不输出标题、解释、编号或 JSON。

## 规则

1. 只写用户指定的字段，不写其它字段，不输出前言、说明、收尾语。
2. 严格贴合核心受众：男频重冲突密度与爽点节奏，女频重情感张力与人设关系，全性别兼顾世界观厚度与情感线。
3. 遵守人设标签与背景标签：标签决定主角起点与舞台，不要写与标签冲突的设定，也不要为了贴合标签而丢掉具体细节。
4. 与已填写的其它字段保持一致，不与之矛盾，也不重复它们已有的内容。
5. 不用「史上最强」「无敌」「逆天」等空泛形容词堆砌，用具体可感知的细节代替。
6. 不虚构现实中的真实人名、真实作品名、真实地名以外的现实参照。

## 各字段要求

- 作品名称：给出 1 个书名，不带书名号，控制在 4-12 字，读起来像一个会被读者记住的名字。
- 作品简介：80-150 字，交代背景、主角起点、核心冲突，结尾留一个悬念钩子。
- 角色信息：主角 1 人 + 关键配角 2-4 人，每人一行，格式「姓名｜身份｜目标｜当前状态｜与主角关系」。
- 主角能力：40-100 字，写清能力来源、当前强度、使用代价、成长方向；能力必须有明确边界，不能无限叠加。
