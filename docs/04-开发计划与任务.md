# 04 · 开发计划与任务拆解

> 本文档定义从零到可用的开发路线图，按里程碑拆解为可执行任务。默认按 Flutter + MVP（分镜图先行、视频后置）规划。**本计划需用户确认后启动。**

---

## 0. 里程碑总览

| 里程碑 | 目标 | 交付物 | 依赖 |
|---|---|---|---|
| M0 | 工程初始化 | Flutter 工程 + 基础架构 + 供应商配置 | — |
| M1 | AI 写小说 | 设定/大纲/逐章写作/审校/TruthFiles | M0 |
| M2 | 小说 → 剧本 | 结构化改编 + 剧本编辑器 | M1 |
| M3 | 剧本骨架提取 | 节拍/分段/出镜状态 | M2 |
| M4 | 资产图片生成 | 角色/场景/道具 + 资产画廊 | M3 |
| M5 | 分镜图生成（视频前确认节点） | 分镜提示词 + 参考绑定 + 生成 | M4 |
| M6 | 视频镜头生成（核心） | 视频任务队列 + 分段提示词 + 生成 | M5 |
| M7 | 打磨与发布 | 导出/备份/性能/签名 APK | M6 |

## 2. M1 · AI 写小说

### 任务清单

- [ ] **T1.1** 实现 `NovelBook` / `Chapter` 数据层与小说书架 UI。
- [ ] **T1.2** 实现「设定工坊」：世界观、角色矩阵、故事命题、大纲的编辑与生成（Planner + Architect Agent）。
- [ ] **T1.3** 实现「章节写作」：Writer Agent 调用 LLM，流式输出到编辑器（flutter_quill），支持续写/重写。
- [ ] **T1.4** 实现 `TruthFiles` 7 类状态存储（世界事实三元组/角色矩阵/资源与道具/伏笔钩子/章节摘要/作者意图/当前焦点）与 Settler 增量更新逻辑。
- [ ] **T1.5** 实现「审校」：Reviewer Agent 输出问题清单（OOC/时间线/伏笔/设定冲突），支持采纳建议修订（spot-fix/polish/rewrite）。
- [ ] **T1.6** 实现章节状态管理（草稿/审校中/定稿）与版本记录。

### 验收标准

- 能走通「创意 → 设定 → 逐章生成 → 审校修订 → 状态固化」闭环。
- 连续生成多章后，角色/伏笔/道具在 TruthFiles 中保持一致，审校能发现明显 OOC。

### 验收标准

- 删除任意已有数据的项目 / 书籍 / 剧本 / 镜头 / 资产均成功，无 `FOREIGN KEY constraint failed`，磁盘媒体同步清理。
- 已走完「提取骨架 → 资产 → 分镜 → 视频」的剧本可反复重新提取骨架、重新改编剧本，数据自洽且可在中途失败后无孤儿行。
- 选择超大视频 / 超大文本文件不会导致进程被杀。
- 剧本标题含特殊字符时成片合成仍正确产出到应用文档目录内。
- 手工构造非法深链（`/#/script/abc/...`）在 Release 构建下不崩进程。
- 长书（40 章以上）章节规划与写作不因上下文超限失败。
- 所有 AI 生成入口走统一确认组件；关闭「生成前确认」设置后行为一致。
- 任务中心任一任务状态都能被区分展示，且单任务网络异常不会导致整体停刷。
- 全量 `flutter analyze` 零问题；核心测试通过；CI 绿（走 GitHub Actions，不本地构建）。
